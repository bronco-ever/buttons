🎛️ Buttons Galore

A curated collection of button designs built with pure CSS, focused on animations, hover effects, and interaction feedback. This project serves as a visual and technical exploration of button styles commonly used in modern web interfaces.

The collection includes a mix of original button designs and carefully recreated versions inspired by buttons I’ve encountered across the web. Each button was rebuilt from scratch to better understand the underlying CSS techniques and animation patterns.

✨ Features:
- Multiple button styles with unique hover and active states
- Smooth CSS animations and transitions
- Focus on interaction feedback and micro-interactions
- Clean, reusable class-based structure

🛠️ Tech Stack:
- HTML
- CSS (animations, transitions, pseudo-elements)

🧠 What This Project Demonstrates:
- Strong understanding of CSS animations and transitions
- Ability to recreate and adapt UI components from visual references
- Attention to interaction design and user feedback
- Writing modular, reusable CSS for UI components

📌 Notes:
- Some button styles are original designs, while others are recreations inspired by buttons found online. All buttons were implemented manually to study animation timing, easing, and interaction behavior rather than copying source code directly.

🚀 Potential Improvements:
- Convert buttons into a small reusable component library
- Add theme variations (light/dark)
- Include accessibility states (focus-visible, reduced motion support)
